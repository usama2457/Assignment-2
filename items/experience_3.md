## Building a Website for Halton Water Sports

### What did I do?
I built and now maintain the website for Halton Water Sports, a friend's jet ski rental business on the Burlington waterfront. I started by mocking up the site in Figma Make, then built and launched it in Wix Studio. Along the way I swapped the online booking tool for simple tap-to-call booking links, added a live weather widget for the Burlington waterfront so customers can check conditions before they book, and rebuilt the photo gallery into a clean grid using real photos from the business.

### When did I do it?
2026, and I'm still maintaining it.

### What was good about it?
It's a real website for a real business, not a class project. People actually use it to find the rentals and book a ride, so my design decisions have real consequences. It also gave me hands-on practice with tools used in industry and a strong piece for my portfolio.

### Favourite memory
Getting the live weather widget working. It took some trial and error, but seeing current Burlington conditions show up on the site for the first time made it feel like a professional website instead of a template.

### What I didn't enjoy
Fighting with the tools. Wix has some strange rules, like custom code only accepting full image links, so small things that should take five minutes sometimes took an hour. I also learned the hard way that fancy interactive features aren't worth it if they keep breaking. I ended up choosing simpler solutions that just work.

### Grade: B
For the most part enjoyable. The tool frustrations kept it from being an A, but I learned a lot and I'm proud of the result.
